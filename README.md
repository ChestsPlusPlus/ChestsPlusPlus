Paper plugin that enhances chests and hoppers, with ChestLinks, Auto-Crafting and Hopper filters.

> **This is the `v3` branch: a ground-up rewrite for Paper 26.x and Java 25. It is under active development and not yet usable.**
>
> - The rewrite plan is in [docs/v3-rewrite-plan.md](docs/v3-rewrite-plan.md).
> - The current stable plugin (v2) lives on the [`2.x`](../../tree/2.x) branch.

v3 is a new major version and is **not** backwards compatible with v2 data, commands, permissions or configuration.
